# Real-Time Linguistic Error Detection System (Spell Checker)

An Object-Oriented Programming (OOP) project that analyzes and implements Microsoft Word's real-time spell-checking mechanism using Java Swing, Trie Data Structure, and Damerau-Levenshtein Distance Algorithm.

## 🚀 Key Features
- **Real-Time Word Scanning**: Instant O(L) dictionary search using Trie prefix trees.
- **Visual Highlight**: Dynamic red underline for misspelled terms.
- **Candidate Suggestion**: Suggestion generation using Levenshtein Edit Distance algorithm.
- **Word Replacement**: One-click replacement of erroneous tokens.
